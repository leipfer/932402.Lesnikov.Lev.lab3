# Лабораторная работа №3. Вёрстка макета с помощью Flexbox и Grid

**Выполнил:** Лесников Лев, группа 932402
**Вариант:** 20 — тема «Футуролог и концепт-художник» (технологии и прогнозы)

## Цель
Освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной вёрстки.

## Задание
Дополнить макет страницы из ЛР №1–2:
- Flexbox: навигационное меню (горизонтальное, адаптивное) и карточки (3–4 шт.) в ряд;
- Grid: галерея/дашборд (2–3 колонки, 2–3 строки);
- медиа-запросы для планшетов и мобильных; отсутствие горизонтальной прокрутки;
- контрастность ≥ 4.5:1; семантически верные теги для карточек.

## Содержимое репозитория
- `index.html` — страница с добавленными Flexbox- и Grid-блоками;
- `style.css` — внешний файл стилей;
- `image.jpg` — изображение-портрет;
- `README.md` — описание работы.

## Что реализовано

### Flexbox
- Навигационное меню `.nav-list` (`<nav aria-label>`): горизонтальное, адаптивное
  (колонка на мобильных → строка от 640px); дополнительно `position: sticky` —
  меню всегда остаётся сверху при прокрутке;
- Карточки «Технологии будущего» `.cards-flex`: 4 карточки `<article>` в ряд
  (название, описание, год прогноза через `<time>`).

### Grid
- Дашборд «Прогнозы по сферам» `.grid`: заголовок на всю ширину (`grid-column: 1 / -1`)
  + 3 блока (сфера, прогноз, вероятность через `<data>`);
- на десктопе — 3 колонки × 2 строки, на планшете — 2 × 3, на мобильном — 1 × 4.

### Адаптивность (медиа-запросы)
- карточки: 1 / 2 / 4 (мобильные / планшеты / десктоп);
- дашборд: 1 / 2 / 3 колонки;
- меню: колонка → строка;
- горизонтальная прокрутка отсутствует: `box-sizing: border-box`, `flex-wrap`,
  `overflow-wrap: break-word`, `max-width: 100%` у изображения.

### Семантика и доступность
- карточки — `<article>` с заголовками `<h3>`, ключевые слова прогнозов — `<mark>`,
  год — `<time>`, вероятность — `<data>`;
- контрастность ≥ 4.5:1: текст #e6f7ff на фоне #190341 ≈ 16.9:1, акцент #7df9ff ≈ 14.9:1,
  вторичный текст #9fb9c8 ≈ 9:1, `<mark>` (чёрный на голубом) ≈ 16.9:1;
- фокус-стили для ссылок и полей формы, `alt` у изображения, подписи полей через `<label>`.

### Оформление (из ЛР №2, сохранено)
Неоновый стиль «киберпанк»: обводка текста через `text-shadow`, глитч-эффект карточек
при `:hover`, состояние `:active/:focus/:visited/:hover`, CSS-переменные в `:root`,
позиционирование static/relative/absolute, три способа подключения стилей.

## Проверка критериев

- Адаптивность работает на всех устройствах;
